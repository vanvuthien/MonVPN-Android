# MonVPN for Android

This public repository hosts Android APK releases of MonVPN. The Windows
development repository remains private.

## Install and updates

Download `MonVPN-Android.apk` from the latest stable
[release](https://github.com/vanvuthien/MonVPN-Android/releases). In the app,
open Settings and tap **Check** under **App updates**. Android will ask you to
confirm installation of a new version. The app verifies the download checksum,
package identity and signing certificate before opening the installer.

Android 10 or newer is required. The VPN connection requires Android's standard
VPN permission.

## Third-party software

The APK includes Xray Core through
[AndroidLibXrayLite](https://github.com/2dust/AndroidLibXrayLite) (LGPL-3.0)
and [hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel) (MIT).
Their source and license terms are available at the linked projects.
